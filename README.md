FlappyPlane — это простая, но увлекательная игра, вдохновленная популярной игрой Flappy Bird. Игрок управляет самолетом, который должен облетать препятствия, пытаясь набрать как можно больше очков. Игра предназначена для развлечения и тренировки реакции, а также способствует развитию координации. FlappyPlane сочетает в себе простоту управления и захватывающий геймплей, что делает её доступной для игроков всех возрастов.

### Управление

- **Игрок:** 
  - Поднятие (Up, W, Space)
  
- **Меню:**
  - Перемещение по меню (Up, Down, W, S)
  - Регулировка громкости (Left, Right)
  - Выбор пункта меню (Space, Enter)
